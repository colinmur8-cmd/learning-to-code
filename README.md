# learning-to-code

Colin's CS fundamentals curriculum, taught through his own sports-betting /
quant projects, ahead of starting Computer Science at UCC in September 2026.

The goal isn't a working betting model — several of those already exist,
built by other people to Colin's spec. The goal is Colin becoming the person
who can build them: real CS fundamentals (data structures, algorithmic
complexity, testing, debugging method, OOP, version control) taught through
projects he's already motivated by, alongside standard first-year CS theory.

See `CLAUDE.md` for how sessions in this repo should run, and `PROGRESS.md`
for a running log of what's been covered and what's next.

## Layout

```
projects/
  01-beginner/            odds parsing, implied probability, win/loss tracking
  02-elo/                 Elo rating system from scratch
  03-backtesting-engine/  file I/O, pandas/numpy, walk-forward validation
  04-automation/          API integration, async, defensive coding
  05-engineering-practice/ git workflow, tests, CI, applied to a live project
```

Each stage's folder has its own README with what it teaches and a starting
exercise — not a solution.
