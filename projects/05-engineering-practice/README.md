# 05 — Stretch: engineering practice

**What this teaches:** git workflow beyond `add`/`commit`/`push` (branches,
meaningful history, resolving conflicts), writing a real test suite rather
than ad-hoc checks, structuring a multi-file project (package layout,
imports, config vs. code), a basic CI pipeline, and code review habits.

Applied to whichever of the live projects (football model, GAA Elo,
PongBot, Puntrr) Colin wants to harden once its underlying logic already
works. This stage is about making an existing thing production-shaped, not
about new algorithmic content.
