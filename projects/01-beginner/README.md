# 01 — Beginner: odds & probability basics

**What this teaches (software engineering side):** writing small pure
functions, basic control flow, reading/parsing plain text data (CSV),
and *proper testing* from day one — not "run it once and eyeball the
output."

**What this teaches (domain side, secondary):** how decimal odds convert
to implied probability, and what "overround" (the bookmaker's margin)
means. Useful, but this is the math, not the CS — don't confuse fluency
here with fluency in the fundamentals.

## Suggested first exercise

Before any code gets written together: given a decimal odds value (e.g.
`2.50`), what's the formula for the implied probability it represents, and
what would you check for to know if you'd got the sign/direction of the
formula wrong? Write down your answer (a sentence is fine) and a first
attempt at the function signature before the next session — even if the
body is just `pass` or a guess.

Nothing else goes here until that attempt exists.
