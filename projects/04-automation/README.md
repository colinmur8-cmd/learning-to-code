# 04 — Advanced: automation & live integration

**What this teaches:** networking basics (HTTP, REST APIs), async code and
why it matters when polling flaky external services, structured error
handling and retries, logging, and defensive coding for something that
runs unattended and can touch real money (Betfair/Smarkets API, a
Discord-signal parser like PongBot).

**Domain side (secondary):** the specifics of any one betting exchange's
API, signal format, or staking rules.

Not started yet — this stage assumes solid testing and error-handling
habits from earlier stages; skipping ahead here without those is how
unattended automation loses money quietly.
